# 連鎖演算 暗算トレーニング ゲーム

3〜5つの四則演算を連続で暗算するゲームです。制限時間30秒。

## 機能

- 難易度4段階: Easy(2演算・小さい数字) / Medium(3演算) / Hard(4演算) / Expert(5演算・大きい数字)
- 演算は整数のみ、中間結果も整数になるよう安全に生成
- 制限時間30秒のカウントダウンバー（残り10秒で赤くなる）
- スコア・正解数・不正解数のリアルタイム表示
- キーボード Enter キーで回答送信
- 週次正答率グラフ（localStorage 保存・過去7日分表示）

## 技術仕様

- 静的SPA（単一 index.html）
- Tailwind CSS CDN
- XSS対策: textContent で表示、parseInt で入力を数値に変換
- localStorage: 週次正答率記録に使用
